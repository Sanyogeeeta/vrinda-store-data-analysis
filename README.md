# Vrinda Store Data Analysis

## Project Overview

This project analyzes Vrinda Store's sales data using Microsoft Excel to identify sales trends, customer behaviour, product performance, and other useful business insights.

## Objective

The main objective of this project is to analyze sales data and generate meaningful insights that can support better business decision-making.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Charts and Visualizations
* Data Cleaning
* Data Analysis

## Key Analysis Areas

* Sales performance
* Customer demographics
* Order status
* Product categories
* Sales trends
* Customer purchasing patterns
